# pode abrir · Kit de marca

## Escolha do arquivo

| Uso | Arquivo ou pasta |
| --- | --- |
| Cabeçalho do site ou apresentação | `svg/pode-abrir-assinatura-grafite.svg` |
| Assinatura sobre fundo escuro | `svg/pode-abrir-assinatura-branco.svg` |
| Apenas o cadeado com a porta | `svg/pode-abrir-simbolo-grafite.svg` ou a versão branca |
| Editor que aceita imagens raster | `png/` contém assinaturas de 480, 1200 e 2400 px de largura e símbolos quadrados de 128 a 1024 px |
| Aba do navegador | `web/favicon.svg` e `web/favicon.ico` (16, 32 e 48 px) |
| Atalho na tela inicial | `web/apple-touch-icon.png` para iOS e os ícones de 192 e 512 px para o manifesto web |
| Foto de perfil | `social/avatar-1024.png` (margem para recorte circular) |
| Prévia de link em redes e mensageiros | `social/compartilhamento-1200x630.png` para a propriedade Open Graph `og:image` |

Os quatro SVGs da pasta `svg/` têm fundo transparente, letras em curvas e a porta vazada. As imagens em `png/` também têm fundo transparente. Os arquivos de redes sociais e os ícones para atalhos usam fundo marfim.

## Cores

| Cor | Hex |
| --- | --- |
| Grafite | `#2C2923` |
| Marfim | `#FCEEDB` |
| Branco | `#FFFFFF` |

Grafite e marfim são cores planas extraídas da arte aprovada. Para trocar a cor de um SVG da pasta `svg/`, edite o atributo `fill` dos caminhos. Preserve a proporção ao redimensionar.
